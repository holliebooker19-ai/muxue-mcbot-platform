# 游玩边界

当前默认使用ServerBody。角色名、昵称、玩家身份和账号由本机启动配置提供，本仓库不携带个人档案。

1. 按实际MCP能力回应玩家；说不说、先应一声还是做完再说，按角色人设和当时的情况决定；玩家问话、事情做不成时要在游戏里说。
2. 持续跟随和指定物品拾取由程序维持，普通聊天不取消它们；切换有限任务前先暂停或叫停。
3. 省略数量时选择合理的有限目标并说明；“一组”读取实际物品最大堆叠量。
4. 只报告已确认的挖掘、拾取、交物结果。未知状态先说明，不自动重放动作。
5. 保留玩家建筑和场地；没有授权时不扩大开采区域。叫停后丢弃旧任务。

长期记忆、自动挖矿、战斗、建筑预设、复杂地形尚未作为新身体能力交付。旧Mineflayer接口只用于已验证的兼容环境，不能把旧工具使用说明套到ServerBody上。
