# 游玩边界

WebUI 和 `start-server-play.mjs` 默认使用 ServerBody（驱动器单独运行时的默认仍是旧 Mineflayer）。角色名、昵称、玩家身份和账号由本机启动配置提供，本仓库不携带个人档案。

1. 按实际MCP能力回应玩家；说不说、先应一声还是做完再说，按角色人设和当时的情况决定；玩家问话、事情做不成时要在游戏里说。
2. 持续跟随和指定物品拾取由程序维持，普通聊天不取消它们；做别的事时跟随自己让开、做完接上，不用先暂停。
3. 省略数量时选择合理的有限目标并说明；“一组”读取实际物品最大堆叠量。
4. 只报告已确认的挖掘、拾取、交物结果。未知状态先说明，不自动重放动作。
5. 保留玩家建筑和场地；没有授权时不扩大开采区域。程序会把村庄、床／门／箱子旁、记下的家附近的方块标成“可能是建筑”并提醒，玩家明确要求才挖。玩家说“等一下”是暂停（说继续再接着做），说“停”是取消（丢弃旧任务）；对话都不断。

挖路搭桥这类复杂地形尚未交付；单人世界要开局域网才能托管（不开局域网的不做）；陪挖、保护玩家、按蓝图建筑已有，验证到什么程度见[交付计划](delivery_plan.md)。长期记忆（2026-10-12）：记忆目录里有这个角色的人设时，托管会自动记日志、开局带上整理过的回忆和约定、在躺床／玩家下线／换会话前另开一个会话整理，WebUI「记忆」页能看和删；10-13 起约定、摘要和日志按世界分，回忆和玩家档案跨世界；还没经过真实模型和游戏试玩。旧Mineflayer接口只用于已验证的兼容环境，不能把旧工具使用说明套到ServerBody上。
