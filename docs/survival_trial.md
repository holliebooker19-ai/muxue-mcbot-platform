# 试玩步骤

适用于 MC 1.21.1 / NeoForge 21.1.217 及以上（21.1 线，实测用 21.1.217） 的独立服务器（或开了局域网的单人世界）、本机 Agent、单个 Bot。玩家只开自己的客户端，Bot 是服务器里的假玩家。能做什么、验证到什么程度以[交付计划](delivery_plan.md)为准，本页只讲怎么开始玩。2026-10-12 更新；10-05 首版验收时的旧步骤见 git 历史和[首版验收](archive/server_alpha_release_validation.md)。

## 准备

1. 构建 `client-runtime`（`npm ci`、`npm run build`）和 `mods/mcbot-server-control`（`./gradlew.bat build`），把核心 jar 装进服务器的 `mods`。也可以用 `node scripts/package.mjs` 打绿色版（自带 Node，jar 在它的 `mods` 里，双击 `启动 mcbot.cmd` 开 WebUI，见[开发文档](dev.md#打包绿色版)）；给别人用的发布版还没出。支持的 Mod 和确切版本见 [compat.json](../compat.json)。想用示例适配就再装对应的附属模组和被适配的 Mod（见 `mods/mcbot-*/README.md`）。改服务器前先备份存档。
2. 启动服务器，确认自己能进。服务器会生成 `config/mcbot-server-control/connection.json`，里面有控制令牌，只留在本机，不要发给别人。
3. Agent 账号在本机登录好（Claude Code、Codex 或 DeepSeek Harness）。用哪个账号由自己选，程序不会自动切换或复制登录。
4. 单人世界：把核心 jar 放进客户端实例的 `mods`，进世界后按 Esc 选「对局域网开放」再托管（不开局域网会拒绝接管，见[单人模式](singleplayer_design.md)）；连接文件用实例里的那份。

## 用 WebUI 启动

```pwsh
node scripts/webui.mjs --open
```

在「配置」页新建一份配置：

- Agent、账号目录、模型、思考强度：试玩一般用 low。
- 连接文件：填服务器的 `connection.json`，点「检查」能看到角色名和世界。
- 记忆目录：放人设和玩家档案的目录（人设放在 `<记忆目录>/<Bot 游戏名小写>/persona.md`，找到时旁边会显示）。留空时 Claude 用仓库的 `memory` 目录，Codex、dsh 用 `runtime/<agent>-memory`（三家要共用就填同一个目录）；没有人设时说话会比较像客服。
- 蓝图目录：建筑用的蓝图（`<名字>.json`，方块是相对最小角的 `[x, y, z, "方块[状态]"]`）放在这里，留空用 `runtime/blueprints`。
- 保护玩家：默认开，可以调范围、撤退血量、用不用弓和盾。
- 外观：服务器装了 YSM 和 YSM 适配时出现，从服务器上的模型里选，每次启动托管时套用。

点「保存并启动托管」。「监控」页能看到游戏聊天、AI 的回复和工具调用；「叫停」是急停：撤销控制、结束 AI 这一轮（对话保留），等新指令；「停止托管」让 Bot 下线。角色上次死了的话，启动托管时会先重生。

命令行版本（WebUI 也是调用它；只要 Node，`start-server-play.ps1` 是同样参数的 PowerShell 写法）：

```pwsh
node scripts/start-server-play.mjs --connection-file '<服务器>/config/mcbot-server-control/connection.json' --agent claude --config-dir '<账号目录>' --memory-dir '<记忆目录>' --effort low
```

加 `--prepare-only` 只检查配置、不启动。

## 可以试的

在游戏聊天里用 Bot 的名字或昵称叫它：

- “跟着我”“等一下”“继续跟”。跟着的时候它会保护你：靠近你的怪会去打，血少了往你这边撤。
- “砍这棵树”“砍三棵树”“挖几个铁矿”。它会自己找、走过去、垫高、捡掉落，做完在聊天里说结果。
- “帮我做一把铁镐”“把这些铁烧了”“附魔一下这把剑”。附魔、铁砧这类先预览，问过你再做。烧东西、酿药默认放进去就去做别的，好了（或者没燃料停了）它会知道，再回去取；酿药每段好了它会回去加下一段的料。想让它守着就说“等着烧完”“等着酿完”。
- “帮我收一下麦子”“把这两头牛喂一下”“在这开块地”。
- “记住这里是家”“回家”。晚上在家附近会提醒你睡觉；你上床它也会去找床。
- 走远路：“去 300 -500 那里”，或者回几百格外记过的地点（最远 2000 格）。会绕开山崖、游过河，走不到会说卡在哪。
- 盖东西：“在这盖个 3x3 的小亭子”“照蓝图 xx 在这盖”。它会先列材料，缺的告诉你；背包里留些泥土或木板，够不着时垫高用，盖完收回。楼梯、半砖、原木、门、火把会按要求的朝向放。
- “穿上这件胸甲”“盾牌拿到副手”。
- 打招呼、让它点头、跳个舞（装了 YSM 时能播模型动画）。
- 做事中途说“等一下”（暂停：手上的事停下，跟随停在原地，保护照旧），或者“停”（取消：手上的事、跟随和保护都结束），再给一个新任务。叫停的词见 `client-runtime/player-stop.json`。

## 当前限制

- 建筑会垫高、放临时靶块，会从垫脚柱迈上盖好的楼板和屋顶、盖完走回柱子拆掉，被困在高处会往下跳（落地后至少留一半血）；不会搭脚手架走廊。大房子要多叫几次 build（每次默认 4 分钟，已经对的会跳过）。两层的测试木屋一楼、二楼基本都能盖完，屋顶最窄的屋脊和墙角里竖放的柱子会剩一些，结果里会列出哪些没盖；不会用模组机器（只认登记了适配的）。长途行走会绕崖、游过河，但不挖不搭：被陡崖或深谷挡住时会停下，说清楚走到哪、离目的地还有多远，需要你带路。
- 托管途中死了：WebUI 启动的托管会原地复活后自动接上，告诉 AI 死因，并去捡死亡掉落、接上之前的跟随和保护；命令行不带 `--wait` 时要重新启动托管。
- 很多能力只在平坦隔离服实测过，自然地形、复杂地形、真实模型下的表现以试玩为准；具体每项的证据见交付计划。
- 程序遇到结果不确定（unknown）时不会自动重试，会如实报告，由你决定接下来怎么做。
